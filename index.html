Hero

Ik bouw digitale oplossingen waar grote IT-bedrijven op kunnen schalen.

Ik ben een junior developer die creatieve ideeën omzet in robuuste software. Met React, Java, C# en Python lever ik oplossingen die zowel technisch sterk als gebruiksvriendelijk zijn. Voor teams met ambitie combineer ik kwaliteit, snelheid en samenwerking.

Over mij

Mijn interesse in development begon met een eenvoudige vraag: hoe maak je complexe processen duidelijk en bruikbaar voor mensen? Als junior developer combineer ik een frisse blik met discipline in uitvoering. Ik werk graag op het snijvlak van front-end en back-end, waar React zorgt voor intuitieve interfaces en Java, C# of Python voor een betrouwbare technische kern. Ik leer snel, neem eigenaarschap over mijn taken en denk actief mee over verbetering. In teamverband waardeer ik heldere communicatie, korte feedbacklussen en een gezamenlijke focus op impact. Zo lever ik niet alleen werkende features, maar ook code die op lange termijn onderhoudbaar blijft.
